# CASOS DE PRUEBA - cards-service

Este directorio contiene los casos de prueba para el microservicio de tarjetas (cards-service).  
Incluye pruebas de:
- Happy path (escenario ideal)
- Errores esperados
- Casos de éxito/alternativos

Todas las pruebas están diseñadas considerando que las integraciones externas se mockean (ver MOCKS.md).

Estructura sugerida:
- Un archivo `.md` por cada caso de prueba.
- Documentación de los mocks en `MOCKS.md`.
